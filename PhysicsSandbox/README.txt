СИМУЛЯТОР ФИЗИКИ В ДВУХМЕРНОМ ПРОСТРАНСТВЕ
C# / .NET Framework 4.8 / Windows Forms / Aether.Physics2D 1.7.0

БЫСТРЫЙ ЗАПУСК
1. Полностью распакуйте архив.
2. Откройте папку bin/Release и запустите PhysicsSandbox.exe.
3. Рядом с EXE должна оставаться Aether.Physics2D.dll.
4. Нажмите «Пуск»: начнётся движение демонстрационных тел.
Требуется Windows с .NET Framework 4.8. Интернет для работы не нужен.

РАЗРАБОТКА
Откройте PhysicsSandbox.sln в Visual Studio 2019/2022 с компонентом
«Разработка классических приложений .NET» и targeting pack .NET Framework 4.8.
Нажмите F5. Библиотека уже включена в packages, восстановление NuGet не требуется.
Интерфейс создаётся программно: файла MainForm.Designer.cs нет.

ПЕРВЫЙ ЭКСПЕРИМЕНТ
Нажмите «Пуск», затем потяните динамическое тело левой кнопкой мыши.
Нажмите «Пауза», выберите инструмент «Создать объект», форму и тип.
Щёлкните в области сцены. Новое тело должно полностью помещаться в границах.
Вернитесь к инструменту выбора и снова нажмите «Пуск».
Выберите тело мышью — в правой панели появятся его свойства.
Меняйте ширину, высоту, плотность, массу, трение, отскок или скорость:
значения применяются сразу, кнопки «применить» нет. При смене размеров
фигура пересоздаётся, а положение, угол и скорости сохраняются.

УПРАВЛЕНИЕ
Пуск — начать или продолжить. Пауза — остановить расчёт.
Сброс — вернуть состояние перед последним запуском после создания/сброса сцены.
Шаг — перейти на один фиксированный шаг и остаться на паузе.
Демо — восстановить демонстрационную сцену. Очистить — удалить пользовательские тела.
Сохранить/Загрузить — XML с настройками мира, временем, геометрией и скоростями.
Скорость времени: 0.25×, 0.5×, 1×, 2×, 4×.
Колесо мыши — масштаб; «Вписать сцену» — исходный масштаб.
ПКМ — переключиться на выбор; Delete — удалить выбранное тело.
Перетаскивание через FixedMouseJoint доступно во время выполнения симуляции.
Статические и кинематические тела мышью не перетаскиваются.

ПАРАМЕТРЫ
Размер мира 24 × 16 м, границы сохраняются при изменении размеров окна.
Ось X направлена вправо, Y вверх (как в физике) — экран переворачивается при отрисовке.
Гравитация по умолчанию (0; -9.81) м/с²: отрицательная Y означает падение вниз.
Шаг по умолчанию 1/60 секунды, в интерфейсе задаётся в миллисекундах.
Параметры гравитации и шага действуют сразу.
Поля трения/отскока задают параметры для новых тел. По умолчанию: трение 0,35, упругость 0,2. Свойства выбранного тела
изменяются отдельной группой полей — каждое изменение применяется мгновенно.
Массу можно задать напрямую: плотность пересчитывается как масса ÷ площадь.
Статические тела неподвижны. Кинематические движутся с заданной скоростью
и не останавливаются столкновениями со статическими границами мира.
Контакты в строке состояния — касающиеся пары физических элементов.
Пружины и собственный физический решатель в эту версию не входят.
XML восстанавливает параметры тел, но не внутренний кэш решателя контактов.

СТРУКТУРА
MainForm.cs — интерфейс, цикл с накопителем времени, отрисовка GDI+, мышь.
PhysicsWorld.cs — данные сцены, Aether.Physics2D, проверка файлов, XML.
Checks.cs — проверки физики и сериализации, не входит в основной проект.

ПРОВЕРКА СБОРКИ
EXE собран Mono C# Compiler. Запуск окна проверен под Mono в Linux/Xvfb.
В checks-result.txt приведены результаты проверок физики и XML.
Проверка непосредственно в Windows в данной среде не проводилась.

ПОДСКАЗКИ
У каждого элемента управления есть всплывающая подсказка: наведите курсор и
подождите около половины секунды. Тот же текст выводится в строке состояния
внизу окна. Подсказка по текущему инструменту отображается поверх сцены.

СТРУКТУРА КОДА
Program.cs            точка входа, запуск главной формы
PhysicsWorld.cs       физическая модель: тела, свойства, сохранение сцен
SimulationCanvas.cs   модуль отрисовки (двойная буферизация)
MainForm.cs           интерфейс, обработка мыши, мгновенное применение свойств
Checks.cs             автоматические проверки физики (консольные)
UiChecks.cs           проверка подсказок и мгновенного применения (без человека)

Все классы и методы снабжены комментариями на русском языке.
